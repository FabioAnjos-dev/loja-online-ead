# Loja Online

Projeto de estudo de uma loja online em JavaScript, feito durante o curso de Análise e Desenvolvimento de Sistemas.

## Funcionalidades

- Tela de login (`login.js`)
- Cálculo do total da compra (`app.js`)

## Tecnologias

- JavaScript

## Como rodar

1. Clone o repositório:
   `git clone https://github.com/FabioAnjos-dev/loja-online-ead.git`
2. Entre na pasta:
   `cd loja-online-ead`
3. Execute com Node:
   `node app.js`
